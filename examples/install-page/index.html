Install Download Tool

Files at or above the site threshold download in this desktop app. Install it for your system, then return to the file and click Download again.

These three links are placeholders on http://127.0.0.1:9090. Point them at the Windows, macOS, and Linux installers you publish. Download URLs in this project use HTTP.

  • Windows DownloadTool-Setup.exe
  • macOS DownloadTool.dmg
  • Linux DownloadTool.AppImage

After install

  1. Open Download Tool. It listens only on 127.0.0.1:29128.
  2. Go back to the file page and click Download again.

The website passes a short-lived http:// ticket (downloadUrl). The app does not take a server account or password. If the ticket has expired, click Download on the site again to get a new one.
